# **Посмотри в окно**

## **Описание проекта**

### Интерактивный веб-интерфейс для просмотра городских пейзажей с возможностью фильтрации по различным параметрам.

## **Основные функции**

###

- Фильтр по городу — выбор локации для просмотра
- Фильтр по времени суток — настройка отображения (утро, день, ночь)
- Система поиска — быстрый доступ к нужным видам
- Пагинация — кнопка "Показать еще" для загрузки дополнительных изображений

## **Структура интерфейса**

## _Форма фильтрации_

- Выбор города — выпадающее меню с локациями
- Время суток — переключатели (радиокнопки)
- Кнопка поиска — активация фильтрации

## _Основной контент_

- Заголовок — название проекта
- Блок результатов — отображаемые виды
- Уведомление — сообщение при отсутствии видео

## **Технологии**

- HTML — структура и разметка
- CSS — стилизация и адаптивный дизайн
- JavaScript — интерактивность
